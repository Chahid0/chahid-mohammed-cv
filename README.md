- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)

- Mise en page entièrement responsive (mobile / tablette / bureau)

## 🚀 Déployer avec GitHub Pages

1. Aller dans **Settings** du dépôt
2. Ouvrir la section **Pages**
3. Sous *Source*, sélectionner la branche `main` et le dossier `/ (root)`
4. Enregistrer — le lien du site apparaîtra après quelques instants
